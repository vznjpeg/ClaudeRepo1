Privacy Policy
Last updated: February 20, 2026  /  Version 2.0.0
MuscleTick is a Chrome extension that helps you stay focused by blocking distracting websites, hiding attention-grabbing page elements, and requiring a small bodyweight exercise before you can access a site you’ve banned yourself from. This policy explains exactly what data we collect, how it stays on your device, and what we never do with it.

1. Who We Are

MuscleTick is an open-source Chrome browser extension. It operates entirely within your browser. There is no company server, no user accounts, no analytics platform, and no backend infrastructure of any kind.

2. Data We Collect & Where It Lives

MuscleTick collects only what is necessary to deliver its features. The table below describes every category of data the extension touches.

3. Permissions Explained

Chrome displays a list of permissions when you install MuscleTick. Here is exactly why each is required:

  • storage — Read and write your block list, settings, and statistics to chrome.storage.sync and chrome.storage.local.
  • declarativeNetRequest / declarativeNetRequestFeedback — Redirect navigation to blocked domains to the exercise challenge page. The redirect happens entirely in the browser; no data is sent to any server.
  • alarms — End timed focus sessions automatically after the chosen duration.
  • tabs — Detect which platform you are currently visiting so the Hide tab shows the correct element controls, and track navigations for the internal browsing history feature.
  • history — Query Chrome’s built-in history to count how many times you have visited your blocked domains in the past 7 days. Displayed only to you; never stored or transmitted.
  • identity — Reserved for potential future features requiring Google account verification for sync. Not actively used in the current release.
  • host_permissions (<all_urls>) — Required so content scripts can run on supported platforms (Instagram, Facebook, YouTube, Twitter/X, LinkedIn) to hide distracting page elements.

4. Content Scripts & Element Hiding

When you visit Instagram, Facebook, YouTube, Twitter/X, or LinkedIn, MuscleTick injects a content script that reads your element-hiding preferences and adds CSS classes to hide the sections you have toggled off (e.g. Stories, Reels, Shorts, Trending, Sponsored Posts).

The content script does not read page content, does not capture text or images from those pages, does not exfiltrate your social media data, and does not communicate with any external server. It only modifies the visual presentation of the page inside your browser.

5. Exercise Challenges

When you navigate to a blocked site, MuscleTick presents a challenge page asking you to complete 2 reps of a randomly selected bodyweight exercise before unlocking navigation. Rep completion is confirmed by a button tap only. No biometric data, camera access, or movement sensor data is used or requested. The exercise type and rep count are stored locally as part of your aggregate statistics only.

6. Data We Never Collect

We never collect
  • Your name, email, or any identity information
  • Passwords or form input from any site
  • Full URLs or page content of sites you visit
  • Photos, camera, or microphone data
  • IP addresses or location data
We never do
  • Send data to a remote server or API
  • Use third-party analytics or tracking SDKs
  • Sell, rent, or share your data with any party
  • Display advertisements
  • Run background crypto-mining or unrelated processing

7. Cross-Device Sync via Google

MuscleTick uses chrome.storage.sync to keep your settings consistent across devices. This works through Chrome’s built-in sync infrastructure, tied to your Google account. MuscleTick does not interact with Google’s servers directly — Chrome handles all sync transport. Data synced is limited to your block list, categories, schedule, element-hiding preferences, exercise toggle, and aggregate statistics. Your internal browsing history is stored only in chrome.storage.local and is never synced.

For details on how Google handles synced extension storage, see Google’s Privacy Policy.

8. Data Retention & Deletion

All data persists until you explicitly remove it. You have full control:

  • Popup → Stats tab → Reset Statistics to clear all aggregate counts at any time.
  • Options → Browsing History → Clear to wipe all internal history entries from this device.
  • Options → Reset Everything to erase all data from both sync and local storage across all signed-in devices.
  • Uninstalling MuscleTick removes all chrome.storage.local data immediately. Chrome also removes chrome.storage.sync data on uninstall.

9. Third-Party Services

The blocked-site interstitial page displays a random photograph sourced from Unsplash via a direct <img> tag. When your browser loads the image, a standard HTTP request is made to Unsplash’s CDN. Unsplash’s Privacy Policy applies to that request. No query parameters, user identifiers, or extension data are included.

Beyond these image loads, MuscleTick makes no outbound network requests of any kind.

10. Children’s Privacy

MuscleTick does not knowingly collect personal information from children under the age of 13 (or the applicable age of digital consent in your jurisdiction). Because the extension collects no personal information from any user, it presents no particular risk in this regard. If you have concerns, please open an issue on GitHub.

11. Changes to This Policy

If we make material changes to this privacy policy, we will update the “Last updated” date at the top of this page and increment the version number. For significant changes, we will note them in the extension’s release notes on GitHub.
